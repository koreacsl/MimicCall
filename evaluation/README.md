## Datasets (datasets/)

### `csvs/`

Sample data of syscall - function.

### `cve_results_5.4.0.csv`

root cause function - MimicCall list data in kernel 5.4.0.

### `cve_results.csv`

Sample data for table 2.

### `filters/`

CVE patch records obtained from kernJC. This is the original/normalized patch metadata.

### `cve_patch.yaml`

CVE patch records obtained from kernJC. This is the original/normalized patch metadata.

### `rc_functions.yaml`

List of vulnerable (root-cause) functions extracted from `cve_patch.yaml`. Each entry includes location and function name information.

### `vuln_version.yaml`

Kernel version information for each CVE — lists affected (vulnerable) kernel versions.

### `kallsyms_4_4.txt`, `kallsyms_5_4.txt`, `kallsyms_5_15.txt`

Kernel symbol listings for the corresponding kernel versions. These files are provided as references when mapping vulnerable functions to kernel symbols and verifying addresses/names.

### `filters/`

A dataset of per-binary system-call filter outputs generated by five different tools used in the study. The `filters/` directory contains multiple subfolders (e.g., `C2C`, `confine`, `sysfilter`, `syspart`, `TSP`) with per-service and per-binary output files such as seccomp profiles, `.out` dumps, JSON summaries, and text transcripts.
